# UDAAN — Teacher Guide & Classroom Intervention Protocol

## 1. Executive Summary
UDAAN (Understanding-Driven Adaptive Academic Navigator) is designed to empower mathematics teachers by diagnosing the specific conceptual misunderstandings that cause errors in Class 8 Rational Numbers, rather than simply scoring students right or wrong.

---

## 2. The Learning Detective Workflow
When a student makes an error during diagnostic practice, UDAAN initiates the **Learning Detective**:
1. **Solve:** Student attempts an NCERT-aligned diagnostic question linked to a concept and its prerequisite.
2. **Detect:** The system maps the chosen distractor to an explicit misconception tag.
3. **Confirm:** The system generates a targeted follow-up question to test the hypothesis:
   - *Careless Slip:* If the follow-up is answered correctly, the student is gently guided to retry without penalty.
   - *Confirmed Misconception:* If the follow-up exhibits the same error pattern, targeted pedagogical support is activated.
4. **Targeted Support:** The learner receives multi-modal scaffolding:
   - A plain-language mathematical rule.
   - A step-by-step worked example with an interactive visual number line.
   - A refresher link to the prerequisite concept (e.g., Equivalent Fractions & LCM).
5. **Fresh Reassessment:** The learner is presented with a fresh question using **new numbers** that assesses the exact same underlying learning objective.
6. **Mastery Update & Action:** If the student passes reassessment, mastery is updated and progression resumes. If difficulty persists, an **Explainable Teacher Action Card** is generated.

---

## 3. Explainable Teacher Action Cards
Every Action Card generated by UDAAN is transparent and human-reviewable. It specifies:
- **Observed Evidence:** Exact answer sequence, distractor chosen, and timestamp.
- **Triggering System Rule:** The specific rule that fired (e.g., "Reassessment failed after targeted intervention").
- **Pedagogical Suggestion:** A concrete, classroom-tested teaching action (e.g., "15-minute tactile number-line exercise on finding LCM").
- **Teacher Review Actions:**
  - `Accept`: Schedule the recommended intervention.
  - `Edit`: Customize the action notes based on classroom context.
  - `Dismiss`: Reject the recommendation if the teacher has external context (e.g., student was unwell or distracted).
  - `Mark Completed`: Close the loop after intervention is delivered.

## 4. Recurring Misconceptions in Class 8 Rational Numbers
Based on NCERT Chapter 1 diagnostic data:
1. **Added Numerators and Denominators Separately (Prevalence ~38%):**
   - *Symptom:* Computing `(-3/4) + (1/2) = (-3+1)/(4+2) = -2/6 = -1/3`.
   - *Root Cause:* Treating fractions as two independent integers rather than a unified ratio.
   - *Remediation:* Tactile fraction strips and visual slice diagrams emphasizing equal partition sizes.
2. **Ignored Negative Sign During Conversion (Prevalence ~17%):**
   - *Symptom:* Converting `(-3/4) + (1/2)` to `(3/4) + (2/4) = 5/4`.
   - *Root Cause:* Dropping directed signs during multi-step algebraic operations.
   - *Remediation:* Two-color counter manipulatives and signed movement on the horizontal number line.
3. **Sign Slip in Final Numerator Addition (Prevalence ~10%):**
   - *Symptom:* Obtaining `+1/4` instead of `-1/4`.
   - *Root Cause:* Misapplying integer addition rules when negative magnitude exceeds positive magnitude.
   - *Remediation:* Quick daily 3-minute oral drills on integer addition on the number line.

---

## 5. Setting Intervention Thresholds
Teachers can fine-tune system sensitivity in the Teacher Dashboard:
- **Advance Streak (default: 2):** Number of consecutive correct answers required to advance to higher difficulty.
- **Prerequisite Revisit Streak (default: 2):** Number of consecutive errors before routing the student to foundational prerequisite concepts.
- **Teacher Escalation Streak (default: 3):** Number of errors before automatically raising a Teacher Action Card.
- **Misconception Alert Threshold (default: 30%):** Alert trigger when cohort prevalence of an identical distractor exceeds this percentage.
